01 — About

The person behind the markup.

I'm a frontend-focused web developer from Karachi, currently expanding into full-stack territory through the Web & App Development course at Saylani Mass IT. My foundation is solid and boring in the best way — HTML5, CSS3 and modern JavaScript — and on top of it I build responsive interfaces with React.js and Tailwind CSS, integrate REST APIs, and manage real data with Supabase.

What I care about is the same thing this page cares about: clean UI that means something. Pages that load fast, shift never, and read the same way to a browser, a search engine and a screen reader. I debug patiently, pick up new tools fast, and ship projects end to end — not demos.

04 — How I Work

Every project is a pipeline: plan → build → debug.

When something breaks, isolate the stage instead of guessing — the engineering mindset I apply to everything.

01

Input — Plan

Structure first

Sitemap and heading outline before a single tag. User needs mapped to sections — findability over decoration.

02

Process — Build

Component thinking

Meaningful markup, responsive layouts, React components and Tailwind utilities — one source of truth per concern.

03

Output — Debug

Ship what works

APIs tested, states handled, layouts verified on real devices. If it doesn't work everywhere, it isn't done.

DEBUG → broken layout? failed fetch? logic bug? Fix the stage, not the symptom.
