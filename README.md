## ⚙️ Local Setup & Execution

To run this repository locally on your system:

### Prerequisites
Make sure you have **Node.js** (v16+ recommended) and **npm** installed on your machine.

### Steps
1. **Clone the repository:**
   ```bash
   git clone [https://github.com/sarmad-tabassum/portfolio-project-decode-labs.git](https://github.com/sarmad-tabassum/portfolio-project-decode-labs.git)
Navigate to the project directory:

Bash
cd portfolio-project-decode-labs
Install project dependencies:

Bash
npm install
Launch the local development server:

Bash
npm run dev
Open your browser and navigate to http://localhost:5173 (or the local URL provided by your console).
